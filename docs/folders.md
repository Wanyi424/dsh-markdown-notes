# 多级文件夹

笔记库使用真实文件夹组织 Markdown，不需要数据库。已有根目录笔记保持原位，其他工作区共用同一套目录。

## 使用

1. 左侧选择「笔记根目录」或某个文件夹，顶部「新建 / 导入到」显示当前目标位置。
2. 点击标题旁的文件夹加号创建子文件夹；点击「新建」在当前位置创建 Markdown 笔记。
3. 点击箭头展开或收起目录。点击笔记后，其所在文件夹成为新的创建、导入位置。
4. 选择文件夹后，在目标位置旁的「文件夹操作」菜单重命名或删除空文件夹。重命名会保留其中内容；删除仅允许完全空的文件夹，不递归删除。
5. 打开笔记，在「文档操作 → 移动到文件夹」选择目的地，可以移回根目录。原文先保存，再移动文件；同名文件不会被覆盖。
6. 拖入或选择导入的 Markdown 会复制到当时选定的文件夹，原文件保留。同一文件夹中遇到重名会自动加序号。

文件夹中的笔记仍支持自动保存、阅读、源码编辑和并排预览。不同文件夹可以有同名笔记；顶部路径用于区分它们。

## 保存位置迁移

更改整个笔记库的保存位置时，保持子目录结构，复制普通 Markdown 文件和初始化标记，重建空文件夹。新位置保存成功后才清理旧副本和空文件夹。

- 目标同路径文件冲突时停止，不覆盖文件。
- 保存新位置失败时，回退本次新复制的文件和新建的空文件夹。
- 非 Markdown 文件保留在原目录；有其他内容的旧文件夹也会保留并提示。
- 隐藏文件夹、符号链接和 Windows 联接点不进入目录树，也不会跟随其读取、写入或迁移。
- 如果笔记引用了未迁移的附件，需要自行处理附件位置。

## 开发验证

```powershell
npm run typecheck
npm test
npm run build
node scripts/folders-browser-check.mjs
```

文件夹测试覆盖路径边界、同名保护、移动与重命名、保存失败时保留草稿、迁移回退和外部文件保全。隔离浏览器验证使用真实构建界面与 Host API，数据位于临时目录，不改动用户笔记或 DSH profile。

目录仅在打开、手动刷新及文件操作后更新；编辑过程中不会为每次按键扫描磁盘，插件没有新增后台轮询。
