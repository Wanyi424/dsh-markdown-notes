# 多级文件夹

笔记库使用真实文件夹组织 Markdown，不需要数据库。已有根目录笔记保持原位，其他工作区共用同一套目录。

## 使用

1. 点击侧栏中的文件夹即可选中并展开 / 收起。选中的文件夹会高亮，顶部「＋」新建的笔记就放在这里（悬停提示显示目标位置）；点击「全部笔记」在右侧按最近修改时间列出所有笔记，新建位置同时回到根目录。打开一篇笔记时，它所在的文件夹自动成为新的目标位置。
2. 鼠标悬停在文件夹上会出现「＋」（在此新建笔记）和「…」（新建子文件夹、导入到此文件夹、重命名、删除空文件夹）；右键文件夹、笔记或「全部笔记」会弹出对应的菜单。侧栏顶部「…」→「新建文件夹」在当前选中的文件夹中创建子文件夹。
3. 移动笔记：直接把笔记拖到目标文件夹或「全部笔记」上，悬停在收起的文件夹上片刻会自动展开；也可以使用顶栏「…」→「移动到…」或右键菜单，在列表中选择目的地，当前位置会标出且不可选。原文先保存再移动，同名文件不会被覆盖。
4. 拖入的 `.md` 文件导入到鼠标所指的文件夹；拖到其他位置时导入当前选中的文件夹。同一文件夹中遇到重名会自动加序号。
5. 重命名文件夹会保留其中内容；删除仅允许完全空的文件夹，不递归删除。
6. 在侧栏中可用方向键浏览：`↑` / `↓` 移动，`→` 展开或进入，`←` 收起或回到上级文件夹。

文件夹中的笔记仍支持自动保存、阅读、源码编辑和并排预览。不同文件夹可以有同名笔记；顶栏的文件夹路径用于区分它们，点击路径可在侧栏中定位。

## 保存位置迁移

更改整个笔记库的保存位置时，保持子目录结构，复制普通 Markdown 文件和初始化标记，重建空文件夹。新位置保存成功后才清理旧副本和空文件夹。

- 目标同路径文件冲突时停止，不覆盖文件。
- 保存新位置失败时，回退本次新复制的文件和新建的空文件夹。
- 非 Markdown 文件保留在原目录；有其他内容的旧文件夹也会保留并提示。
- 隐藏文件夹、符号链接和 Windows 联接点不进入目录树，也不会跟随其读取、写入或迁移。
- 如果笔记引用了未迁移的附件，需要自行处理附件位置。

## 开发验证

```powershell
npm run typecheck
npm test
npm run build
node scripts/folders-browser-check.mjs
```

文件夹测试覆盖路径边界、同名保护、移动与重命名（包括操作非当前打开的笔记）、保存失败时保留草稿、迁移回退和外部文件保全；浏览器检查另覆盖选中高亮、折叠动画（收拢期间子项不可聚焦，结束后移除）、拖拽移动、移动对话框、多级目录的图标列与竖线对齐，以及「…」菜单的开关与定位。隔离浏览器验证使用真实构建界面与 Host API，数据位于临时目录，不改动用户笔记或 DSH profile。

目录仅在打开、手动刷新及文件操作后更新；编辑过程中不会为每次按键扫描磁盘，插件没有新增后台轮询。
